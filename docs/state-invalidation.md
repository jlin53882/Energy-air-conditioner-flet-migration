# 工作區狀態失效矩陣

本文件定義使用者操作後，各畫面的**輸入**、**結果**與**圖表**應保留或失效。
對應的回歸測試位於 `tests/test_integration_hardening.py`；修改任何一列行為時，
必須同時更新本文件與測試。

## 1. 名詞

- **輸入**：欄位數值、欄位單位、下拉選單與模式選擇（例如錶壓／絕對壓）。
- **結果**：結果卡、關鍵數值、結構化表格與原始文字。
- **圖表**：P-h、T-s、冷凍循環 P-h、濕空氣線圖。
- **失效**：清除結果，並以狀態列提示需要重新計算；不得繼續顯示舊數值。
- **最近一次成功計算的輸入快照**：分析頁在計算成功當下記錄的輸入值，用來判斷
  之後的輸入是否已被修改。

## 2. 矩陣

| 事件 | 輸入 | 結果 | 圖表 |
|---|---|---|---|
| 切換到其他頁面再回來（A → B → A） | 保留 | 保留 | 保留 |
| P-h 與 T-s 兩個路由互切 | 保留 | 失效 | 清除（圖表種類已改變） |
| 同一頁內切換分析項目 | 保留 | 失效 | 隱藏 |
| 切換 SI / Imperial（輸入未修改） | 保留數值與單位 | 以新單位重新呈現 | 重繪 |
| 切換 SI / Imperial（計算後輸入已修改） | 保留數值與單位 | 失效（不得以未送出的輸入重算） | 隱藏 |
| 物性查詢頁修改流體、模式、Reference State 或已知性質 | 保留 | 失效 | — |
| 分析頁修改輸入但未重新計算 | 保留 | 保留（顯示最近一次成功計算的結果） | 保留 |
| 計算失敗 | 保留 | 以錯誤訊息取代 | 隱藏 |
| 錶壓 ↔ 絕對壓切換 | 數值換算為同一個實際壓力，單位維持同尺度 | 不變 | 不變 |
| 大氣壓力欄位修改（錶壓模式） | 錶壓讀值保留，計算時重新換算絕對壓 | 依「分析頁修改輸入」 | 同左 |

## 3. 規則說明

### 3.1 單位切換只改呈現

全域 SI / Imperial 是輸出偏好，不得改寫任何輸入欄位的數值或單位。

- 物性查詢頁保存 SI 結果快照，切換時只重新格式化，不重新查詢。
- 分析頁的模組只輸出格式化文字，切換時需要重新計算才能換單位。重新計算前必須
  比對輸入快照：輸入與最近一次成功計算相同才重新計算；已修改則使結果失效並提示
  「輸入已變更」，不得把未送出的輸入算出的數值當成原結果呈現。

### 3.2 Reference State

- 物性查詢頁的 Reference State 是該流體的 application 要求 policy。
- 壓縮機分析沿用物性查詢頁對同一流體要求的 policy（`requested_reference_state`）。
- 冷凍循環、過熱度／過冷度、冷凝器 Exergy 由 `RefrigerationService` 依流體決定
  policy，不受物性查詢頁影響；熱力圖使用自己頁面上的 Reference State 選單。
- 任何一頁的計算都不得改變其他頁面之後計算所用的 policy。
- 只由狀態差值構成的結果（例如冷凝器 Exergy 的 Δh、Δs）與 policy 無關，
  切換 ASHRAE / IIR 後數值必須相同。

### 3.3 錶壓與絕對壓

依 `docs/hvac-ui-domain-contract.md`：錶壓模式使用錶壓單位（`kPag`、`psig`…），
絕對壓模式使用絕對單位；切換時換算數值以維持同一個實際壓力；大氣壓力無法解析時
維持原模式並提示。適用於過熱度／過冷度判讀與壓縮比。

大氣壓力改變時保留使用者輸入的錶壓讀值（現場儀表讀到的是錶壓），計算時以新的
大氣壓力換算絕對壓。

### 3.4 圖表生命週期

- 每個圖表面板持有一個長期存在的 figure；重繪時清除後重畫，不建立新 figure、
  不累積舊資料序列或標註點。
- 計算失敗或切換分析項目時隱藏圖表；下次成功計算時重畫。
- 熱力圖路由重新進入同一種圖表時不清除已繪製的圖。

## 4. 已知差異（不在 #7 內修改）

- 冷凝器 Exergy 頁的壓力只接受絕對壓力；冷凍循環與壓縮比頁可切換錶壓／絕對壓。
- 物性查詢頁修改輸入會使結果失效；分析頁修改輸入則保留舊結果直到重新計算
  （切換單位時例外，見 3.1）。
- 壓縮機分析跟隨物性查詢頁的 Reference State，冷凍循環則不跟隨。
