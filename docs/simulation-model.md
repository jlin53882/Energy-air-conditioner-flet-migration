# 多元取熱雙效熱泵：動態模擬模型規格

本文件定義「UI 可動起來」所需的動態模擬模型：系統參數、熱力計算方式、電磁閥／模式切換邏輯、
時間步進演算法、需記錄的欄位，以及 UI 動畫元素。數值來源為實驗報告（表 2.1.2–2.1.5、
圖 5.1.5、圖 6.3–6.4）、原廠壓縮機規格與討論後確認的設計決策。

> 狀態：**規格草案（尚未實作）**。標示「假設」的數值為暫定值，取得實測資料後應更新。

### 2.2 切換與保護邏輯

依優先順序判斷（每個時間步）：

| 優先 | 條件 | 動作 | 回復條件 |
|---|---|---|---|
| 1 安全 | Tc ≥ 60 °C（約 38.4 bar）或排氣溫度 ≥ 110 °C | 強制停機、顯示警報 | 手動復歸 |
| 2 冷房模式 | 雙效中熱水 ≥ 40 °C | 關 SV8、開 SV9 → 智慧冷房 | 熱水 ≤ 38 °C：關 SV9、開 SV8 |
| 3 冷房溫控 | 冰水 ≤ 7 °C | 壓縮機停 | 冰水 ≥ 10 °C 且已停 ≥ 3 min（**假設**） |
| 4 暖房模式 | 雙效中冰水 ≤ 5 °C | 關 SV10、開 SV11 → 智慧暖房 | 冰水 ≥ 7 °C：關 SV11、開 SV10 |
| 5 暖房溫控 | 熱水 ≥ 45 °C | 壓縮機停 | 熱水 ≤ 42 °C 且已停 ≥ 3 min |

- 壓縮機最短停機時間：3 分鐘。
- 冰水下限依報告內文採 5 °C（圖 6.4 記載約 7 °C）。

## 3. 計算方法

### 3.1 循環計算（每個時間步）

1. 由模式與水溫決定 Te、Tc（第 1.4 節）。
2. 物性以 CoolProp 計算：
   - `Pe = Psat(Te)`、`Pc = Psat(Tc)`、`PR = Pc / Pe`
   - 吸氣：`T1 = Te + SH`，取 h1、s1、ρ1
   - 排氣：`h2 = h1 + (h2s − h1) / η`，`h2s = h(Pc, s1)`，`T_d = T(Pc, h2)`
   - 液管：`h3 = h(Pc, Tc − SC)`
3. 質量流量：`ṁ = V_d × f × η_v(PR) × ρ1`
4. 能力：`Q_e = ṁ(h1 − h3)`、`W = ṁ(h2 − h1)`、`Q_c = ṁ(h2 − h3)`

可沿用 `domain/refrigeration/vapor_compression.py` 的 `solve_vapor_compression_cycle`，
需另加壓縮機模型（由排氣量求 ṁ）。

### 3.2 水桶能量平衡（顯式 Euler）

```
冷房：
  dT_cold = [ Q_fc − Q_e(進水側) + UA_tank(T_room − T_cold) ] / (m·cp) · dt
  dT_hot  = [ Q_c(若冷凝於板式) + UA_tank(T_room − T_hot) ] / (m·cp) · dt
暖房：
  dT_cold = [ −Q_e(若蒸發於板式) + UA_tank(T_room − T_cold) ] / (m·cp) · dt
  dT_hot  = [ Q_c − Q_fc + UA_tank(T_room − T_hot) ] / (m·cp) · dt
```

- 時間步 dt ≤ 5 s（160 L 下水溫變化最快約 0.025 K/s）。
- 熱水取用量：目前為 0，預留為可調參數。

### 3.3 指標定義

| 指標 | 定義 |
|---|---|
| COP_冷 | Q_e / W |
| COP_熱 | Q_c / W |
| 系統 COP（送風機側） | ∫Q_fc dt / ∫(W + 0.21 kW) dt |
| 雙效 COP | (Q_e + Q_c) / W（僅雙效模式） |

### 4.2 冷房情境（160 L、初始 30 °C、室溫 27 °C、外氣 30 °C、模擬 3 h）

| 時間 | 事件／模式 | Te / Tc | 冰水 / 熱水 | Q_e / 送風機負荷 / W (kW) |
|---|---|---|---|---|
| 0 | 雙效（SV 1,6,7,8,10） | 15 / 35 | 30 / 30 | 15.7 / 0 / 1.89 |
| 6.5 min | 熱水 40 °C → 關 8 開 9 | — | 約 21 / 40 | — |
| 20 min | 智慧冷房（SV 1,6,7,9,10） | 7.0 / 40 | 12.0 / 40 | 11.2 / 6.6 / 2.46 |
| 51.2 min | 冰水 7 °C → 壓縮機停 | — | 7 / 39.8 | — |

3 h 內不會觸發 38 °C 回切。

## 6. UI 動畫元素

| 元素 | 依據 | 表現方式 |
|---|---|---|
| 冷媒管線 | 模式 + 閥件 | 高壓氣（紅）、高壓液（淺紅）、低壓（藍）、未使用（灰）；流動虛線 |

| 控制列 | 播放／暫停、倍速（1×～120×）、冷房／暖房、環境參數 | — |
