# 多元取熱雙效熱泵：動態模擬模型規格

本文件定義「UI 可動起來」所需的動態模擬模型：系統參數、熱力計算方式、電磁閥／模式切換邏輯、
時間步進演算法、需記錄的欄位，以及 UI 動畫元素。數值來源為實驗報告（表 2.1.2–2.1.5、
圖 5.1.5、圖 6.3–6.4）、原廠壓縮機規格與討論後確認的設計決策。

> 狀態：**規格草案（尚未實作）**。標示「假設」的數值為暫定值，取得實測資料後應更新。

- Te 上限 15 °C：避免高水溫時蒸發溫度超出壓縮機運轉範圍。
- 板式蒸發器無 LMTD 資料，維持溫差近似 5 K。

**板式冷凝器 UA = 3.79 kW/K（報告圖 2.1.2–2.1.3）**

```
UA_phx = 13.78 kW ÷ 3.632 K（對數平均溫差）= 3.794 kW/K
```

冷媒側以冷凝溫度 Tc 視為定溫，水側以 ε-NTU 計算（C_r = 0）：

```
NTU = UA_phx / (ṁ_w · cp)
ε   = 1 − exp(−NTU)
Q_c = ε · ṁ_w · cp · (Tc − T_hot)
```

- 驗證：代入報告設計條件（水 1.333 kg/s、進水 54.99 °C、Tc 60 °C）得 Q = 13.79 kW，與報告 13.78 kW 吻合。
- 運轉水量採熱水泵 12.06 GPM = 0.761 kg/s（表 2.1.5）：NTU = 1.19、ε = 0.696、
  ε·ṁ_w·cp = 2.217 kW/K。即 Tc − T_hot ≈ Q_c ÷ 2.217（Q_c 15 kW 時約 6.8 K）。
- 水泵為**定頻泵**，運轉中水量固定，UA 視為定值即可（報告雖寫以變頻控制為設計要素，實際為定頻）。
- 水量由 GPM 換算：12.06 GPM × 3.785 L/gal ÷ 60 = 0.761 L/s，乘水密度約 1 kg/L（設計值，非實測）。
- **UA 在 0.761 kg/s 下沿用 3.79 kW/K**。依板片幾何估算水側熱傳係數，檢查水量降低的影響：

  | 項目 | 1.333 kg/s | 0.761 kg/s |
  |---|---|---|
  | 每流道流速（30 流道、寬 0.106 m、間隙約 2 mm，**假設**） | 0.213 m/s | 0.121 m/s |
  | Re（Dh = 4 mm，56 °C 水） | 1691 | 965 |
  | 水側 h（`Nu = 0.348 Re^0.663 Pr^0.33`） | 11,420 W/m²·K | 7,876 W/m²·K |

  水側熱阻約佔總熱阻 22–25 %，水量降到 0.761 kg/s 後：

  | 總 U 的取法 | UA @ 1.333 | UA @ 0.761 |
  |---|---|---|
  | 軟體熱傳量 ÷ (面積 × LMTD) | 3.79 | 3.46 |
  | 計入軟體裕度 16.4 %（面積有餘裕） | 4.42 | 3.96 |

  兩種取法的 0.761 kg/s 結果（3.46–3.96）涵蓋 3.79，故直接沿用；誤差對 Tc 的影響小於約 0.5 K。
- 限制：未分過熱／冷凝／過冷三區；水溫對黏度的影響、結垢均忽略。

### 1.8 參數推導與限制

**容積效率（餘隙容積模型）**

壓縮機每轉理論吸入 V_d，但汽缸餘隙中殘留的高壓氣體會再膨脹，佔掉部分吸氣空間，
壓縮比越高佔得越多：

```
η_v = 1 − C × (PR^(1/k) − 1)
```

- k = 1.341：R410A 在 7.2 °C 蒸發、18.3 °C 吸氣時的 cp/cv（CoolProp）。
- C = 0.0892：額定點（PR 3.40）需要 η_v = 0.867 才能得到 9.7 kW，反推而得。
  此 C 為「等效值」，同時吸收洩漏、吸氣加熱等損失，非實際餘隙比例（迴轉式實際約 2–4 %）。
- 限制：只用一個額定點校正，曲線斜率由物理式決定。取得原廠多工況性能表後，
  應改用 AHRI 540 十係數多項式擬合冷量與耗電。

| PR | 1.7 | 2.0 | 2.6 | 3.4 | 4.1 | 5.0 |
|---|---|---|---|---|---|---|
| η_v | 0.957 | 0.940 | 0.907 | 0.867 | 0.834 | 0.793 |

**水桶散熱 UA_tank = 0.93 W/K（HDPE 桶外包 50 mm PU 保溫）**

桶體為 160 L HDPE 食品桶（最大外徑 0.51 m、高 0.98 m），以圓柱計算表面積：

```
A = π × 0.51 × 0.98 + 2 × π × 0.255² = 1.570 + 0.409 = 1.979 m²
```

串聯熱阻（每 m²）：

| 熱阻 | 計算 | m²·K/W |
|---|---|---|
| 50 mm PU 發泡（k ≈ 0.025 W/m·K） | 0.05 ÷ 0.025 | 2.000 |
| 外側自然對流＋輻射（h ≈ 9 W/m²·K） | 1 ÷ 9 | 0.111 |
| HDPE 壁約 5 mm（k ≈ 0.45 W/m·K） | 0.005 ÷ 0.45 | 0.011 |
| 合計 | | 2.122 |

```
U = 1 ÷ 2.122 = 0.471 W/m²·K
UA_tank = 0.471 × 1.979 ≈ 0.93 W/K
```

保溫後散熱很小（水溫與室溫差 20 K 時約 19 W），對動態結果影響可忽略。
可用靜置降溫實驗驗證：`UA = m·cp × ln(ΔT₀ / ΔT_t) / t`。

**送風機 UA_fc = 0.44 kW/K（假設）**

採用「進口溫差法」：盤管能力近似正比於進風溫度與進水溫度之差。
以報告額定 8.79 kW、假設額定條件為進風 27 °C、進水 7 °C（常見送風機額定工況），
UA_fc = 8.79 ÷ 20 = 0.44 kW/K。限制：

- 未區分顯熱／潛熱，也未考慮風量與水量變化。
- 室溫固定，代表「送風機能從室內取得的最大能力」，不是建築實際負荷。
- 取得送風機型錄（不同進水溫度的能力）或房間負荷後應更新。

**室外換熱器 UA_out = 0.551 kW/K（以報告冷凝器設計熱量 13.78 kW 反推）**

已移除「固定 10 K 溫差」假設，改為固定 UA_out，每個時間步以二分法求解 Tc（或 Te），
使室外換熱量與壓縮機模型一致：

```
當冷凝器：Tc − T_out = Q_c(Te, Tc) / UA_out
當蒸發器：T_out − Te = Q_e(Te, Tc) / UA_out
```

UA_out 來源：室外換熱器在智慧冷房時必須取代板式冷凝器，排出相同的冷凝熱。
採用報告冷凝器設計熱量 13.78 kW（圖 2.1.2）、設計冷凝溫度 60 °C，並**假設**設計外氣為 35 °C：

```
UA_out = 13.78 kW ÷ (60 − 35) K = 0.551 kW/K
```

限制：設計外氣溫度為假設值；當蒸發器時沿用同一 UA（未考慮除濕、結霜）。
取得室外機型號或額定能力後應更新。

## 3. 計算方法

### 3.1 循環計算（每個時間步）

1. 由模式與水溫決定 Te、Tc（第 1.4 節）。
2. 物性以 CoolProp 計算：
   - `Pe = Psat(Te)`、`Pc = Psat(Tc)`、`PR = Pc / Pe`
   - 吸氣：`T1 = Te + SH`，取 h1、s1、ρ1
   - 排氣：`h2 = h1 + (h2s − h1) / η`，`h2s = h(Pc, s1)`，`T_d = T(Pc, h2)`
   - 液管：`h3 = h(Pc, Tc − SC)`
3. 質量流量：`ṁ = V_d × f × η_v(PR) × ρ1`
4. 能力：`Q_e = ṁ(h1 − h3)`、`W = ṁ(h2 − h1)`、`Q_c = ṁ(h2 − h3)`

可沿用 `domain/refrigeration/vapor_compression.py` 的 `solve_vapor_compression_cycle`，
需另加壓縮機模型（由排氣量求 ṁ）。

### 3.2 水桶能量平衡（顯式 Euler）

```
冷房：
  dT_cold = [ Q_fc − Q_e(進水側) + UA_tank(T_room − T_cold) ] / (m·cp) · dt
  dT_hot  = [ Q_c(若冷凝於板式) + UA_tank(T_room − T_hot) ] / (m·cp) · dt
暖房：
  dT_cold = [ −Q_e(若蒸發於板式) + UA_tank(T_room − T_cold) ] / (m·cp) · dt
  dT_hot  = [ Q_c − Q_fc + UA_tank(T_room − T_hot) ] / (m·cp) · dt
```

- 時間步 dt ≤ 5 s（160 L 下水溫變化最快約 0.025 K/s）。
- 熱水取用量：目前為 0，預留為可調參數。

### 3.3 指標定義

| 指標 | 定義 |
|---|---|
| COP_冷 | Q_e / W |
| COP_熱 | Q_c / W |
| 系統 COP（送風機側） | ∫Q_fc dt / ∫(W + 0.21 kW) dt |
| 雙效 COP | (Q_e + Q_c) / W（僅雙效模式） |
