# HVAC UI 調整方向草稿

三個可互動 HTML 草稿，均同時呈現濕空氣模式切換與狀態查詢條件排列，並含窄螢幕響應式版面。點擊頂部導覽可切換兩個頁面；濕空氣頁切換模式時，會同步變更選中態、目前模式文字及顯示欄位。

- `01-state-first.html`：緊湊分段按鈕；狀態查詢完全隱藏第三條件入口，說明只接受兩個獨立性質。
- `02-guided-cards.html`：引導式模式卡片；狀態查詢保留一個「＋ 新增條件」按鈕，但明確停用並說明原因，作為「隱藏」與「保留入口」兩種產品決定的比較方案。
- `03-explicit-mode.html`：模式明示的大選項切換；性質/數值/單位固定欄位軌道，狀態查詢第三條件入口隱藏。

目前採用 `01-state-first.html` 作為設計參考方向；其餘兩份保留作為方案比較草稿。正式 Flet UI 已依此方向完成模式選取態、第三條件入口隱藏及欄位對齊修改。

這些檔案是非正式、非執行的設計參考，不是可執行事實，內容可能與正式畫面不同；展示數值是假資料，不是程式計算結果，也不能作為 runtime 驗收證據。正式 Flet 程式碼是實際實作依據，`docs/ui-architecture.md` 是預期架構契約。保留原型只為追溯本次設計比較，不應將其當作第二份正式規格維護。
